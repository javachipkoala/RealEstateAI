# RealEstateAI

RealEstateAI is a web-based Real Estate AI Agent application.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- MySQL

## Features

- User Registration and Login
- Property Search
- AI Property Recommendations
- Property Details
- Property Inquiries
- Agent Registration and Login
- Agent Property Posting
- Admin Login
- Agent Approval
- Property Approval
- User Dashboard
- Agent Dashboard
- Admin Dashboard

## Requirements

- Python
- MySQL
- MySQL Workbench
